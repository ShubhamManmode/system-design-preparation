# System Design Learning Path

This repository is a structured learning path for system design topics, covering networking, operating systems, APIs, databases, scalability, architecture patterns, reliability, observability, security, and design interviews.

## What this repo contains
- Core concepts and foundational topics
- Chapter-wise syllabus notes for study progression
- Deep reference notes under the resources section
- Interview-oriented design topics such as HLD and LLD

## Recommended learning flow
1. Start with [SystemDesign/NetworkingAndOS.md](SystemDesign/NetworkingAndOS.md) for the overview.
2. Follow the syllabus chapters in order:
   - [Phase 1 - Networking and OS](SystemDesign/Syllabus/Phase1_NetworkingAndOS.md)
   - [Phase 2 - API Fundamentals](SystemDesign/Syllabus/Phase2_ApiFundamentals.md)
   - [Phase 3 - Database Fundamentals](SystemDesign/Syllabus/Phase2_DatabaseFundamentals.md)
   - [Phase 3 - Core Components](SystemDesign/Syllabus/Phase3_CoreComponent.md)
3. Move to advanced topics such as:
   - [Phase 16 - HLD](SystemDesign/Syllabus/Phase16_HLD.md)
   - [Phase 17 - LLD](SystemDesign/Syllabus/Phase17_LLD.md)
